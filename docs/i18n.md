# Internationalization

BatchPlane uses English as the source locale and bundles Korean by default.

## Add A Language

1. Add JSON resources under `apps/web/src/i18n/locales/{locale}`.
2. Add the locale to `supportedLocales` in `apps/web/src/i18n/locales.ts`.
3. Add a display label to `localeLabels`.
4. Run `pnpm test`.

All locale key sets must match English. Technical identifiers such as `batchId`,
`requestId`, GitHub labels, and Gate `reasonCode` values are not translated.
