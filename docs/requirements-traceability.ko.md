# 요구사항·로드맵·QA 추적표

[English](./requirements-traceability.md)

기준일: 2026-10-06, main `18e7dba78fe27646d61e8b83983e5ceeb7b898a9` 위의
#223 보정.
#232에서 정합화한 실제 열린 이슈 목록을 담당 작업에 반영했다. 이는 작업 추적표이며
모든 요구가 구현·검증됐다는 증거가 아니다. 순서는 [로드맵](./control-plane-migration-plan.ko.md),
제품 의미는 [SRS](./control-plane-srs.ko.md)를 따른다.

## 표 읽는 법

- **존재 / 결함**: 현재 Lite에 흐름이 있으나 명시된 보정과 QA가 남아 있다.
  해당 묶음의 모든 조항이 통과했다는 뜻은 아니다.
- **예정**: 승인된 범위지만 구현을 전달하지 않았다.
- **설계 필요**: 상세 모델·UX·API·플랫폼 결정을 승인받아야 한다.
- **범위 확인 대기**: 이전 요구와 우선순위는 유지한다. 새 확정 로드맵에 명시적
  배치가 없어 상세 범위·시점의 사용자 확인이 필요하다. 선택 상태나 누락 허가가
  아니며 실행 가능한 QA 상세도 대기다.
- ID 범위는 양 끝을 포함한다. 여러 요구가 업무 흐름 QA를 공유하도록 했으며
  ID마다 테스트 하나를 요구하는 것이 아니다.

QA 참조는 [한글 QA 시트](./user-qa.ko.md)로 이어진다. 준비 상태는 테스트 결과가
아니며 [결과 양식](./qa-result-template.ko.md)은 모든 사례를 NOT_TESTED로 시작한다.
Main·플랫폼 설계 행은 현재 클릭해 사용할 수 있는 기능이 아니다.

## 추적 범위 유지

#223 변경은 QA-L05와 연결 흐름인 QA-L01, QA-L09, QA-L15, QA-L18에 영향을 준다.
#226 실행·감사·내처리함 이력 조회, #202 실제 스케줄 검증, #232 사용자 수용을
완료한 것은 아니다. 승인·반려 조작은 권한 없음과 조회 불가를 구분해 표시하며
요청 내용 조회는 유지한다. 과거 결정 기록과 현재 Workspace 정책이 실행을
허용하는지는 별도로 표현한다.
